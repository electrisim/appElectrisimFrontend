Theory · Small-Signal

Eigenvalues on the s-plane

Linearise around the operating point. Mode location = damping + oscillation frequency — no large fault required.

How to read eigenvalues

  • Re(λ) < 0 → stable (decaying)
  • Re(λ) > 0 → unstable (growing)
  • Im(λ) → frequency f = |ω| / 2π
  • ζ = −σ / |λ| → damping ratio

Electrisim results

  • Verdict: stable / marginal / unstable
  • Counts: +, 0, − eigenvalues
  • Least-damped oscillatory modes
  • Participation factors (top modes)

Why run both TDS and EIG?

  • EIG finds poorly damped modes quickly at the current dispatch
  • TDS shows the nonlinear response to a concrete fault clearing time
  • Together: design intuition for inertia, droop, and clearing — without leaving the browser
