3W transformer: PowerFactory → Electrisim

Map loss parameters before comparing load-flow results

PowerFactory

  • Copper losses HV–MV [kW]
  • Copper losses MV–LV [kW]
  • Copper losses LV–HV [kW]
  • (Often no iron-loss field)

Electrisim / pandapower

  • vkr_hv_percent ← HV–MV kW
  • vkr_mv_percent ← MV–LV kW
  • vkr_lv_percent ← LV–HV kW
  • pfe_kw ← iron losses (0 if none)
  • i0_percent ← no-load current
vkr [%] = Pcu [kW] ÷ (10 × Sref [MVA])
