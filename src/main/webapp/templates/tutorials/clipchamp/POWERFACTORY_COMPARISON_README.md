## How to add slides

### Option A — Ready-made PNGs

Drag `powerfactory_comparison_title.png` and `powerfactory_comparison_agenda.png` into Clipchamp.

### Option B — Screenshot from HTML

1. Open `powerfactory_comparison_intro.html` in Chrome (1920×1080 display or F11 fullscreen).
2. Capture each `<section class="slide">` with Win+Shift+S.
3. Import PNGs into Clipchamp.
