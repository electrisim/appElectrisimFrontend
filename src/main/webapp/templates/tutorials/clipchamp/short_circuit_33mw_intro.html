Cable design

Which fault current for which part of the cable?

Electrisim labels every bus with ikss, ip, and ith. Use the right fault type when you map results to conductors versus screens.

Phase conductors

  • Three-phase fault, maximum case
  • ith at clearing time tk
  • Adiabatic check — I²t (IEC 60949)
  • Symmetrical duty · not peak ip

Metallic screens

  • Single phase (phase-to-earth) in the dialog
  • Earth-return current on the screen
  • Ik2E (two-phase-to-earth) in IEC practice
  • Two phase = no earth — not for screens

Vector group

  • YN, D, Y — zero-sequence path
  • Strong effect on 1ph ikss
  • Small effect on 3ph ikss
  • Angle shift ≠ lower 3ph RMS

If 1ph ikss > 3ph ikss on an earthed bus, check the phase conductor against both.
